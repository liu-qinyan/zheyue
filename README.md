# 折页清

一个 2007 年 5 月建的个人主页。2013 年后不再更新。

**打开就能看：<https://liu-qinyan.github.io/zheyue/>**

---

## 这是什么

整个站只有 `index.html` 一个文件。

样式、脚本、图片、声音全在里面：图片是浏览器用 canvas 现画的，声音是 WebAudio 现合成的。
所以把它下载下来、断开网络、双击打开，看到的东西和线上完全一样。

站上没有任何网络请求——没有 CDN、没有外链字体、没有统计脚本，
也不读你的浏览记录、位置、摄像头或麦克风。

## 怎么看

用浏览器打开就行，手机也能看。

页脚那几个不起眼的链接（更新记录、旧页面存档、下载、联系我）比导航栏有意思。
上面有一个地址框，可以手动输入路径——这个站有些东西不在菜单里。

右下角有"找东西"和"设置"。设置里有字号、开关动画、高对比和声音开关，
声音默认是关的，所有能听出来的东西都能用文字或图看出来。

## 关于内容

故事、人物、站点、图片、录音、诗歌全部是虚构的，为这部作品原创。
域名 `zheyue.pages.dev` 是作品里的设定，不是真实存在的站点。

## 本地构建

```
node build/build.js          # 把 build/ 下的源码合并成单文件 index.html
node test/run-tests.js       # 用无头浏览器渲染每个页面并断言
```

`build/` 里是源码：`data/` 放剧情数据，`js/` 放逻辑，`styles.css` 是样式，`entry.html` 是骨架。
`index.html` 是构建产物，不要直接改它。
